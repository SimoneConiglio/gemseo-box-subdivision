# Box subdivision: talk material

This branch holds only the material of a talk on the box-subdivision outer
approximation of
[gemseo-box-subdivision](https://github.com/SimoneConiglio/gemseo-box-subdivision);
the code lives on the other branches.

| path | contents |
|------|----------|
| `presentation/index.html` | a 14-slide deck for a ten-minute talk, with its animations |
| `video/box_subdivision.mp4` | the narrated video, 25 minutes, 1080p |

## Presenting

Download the branch (Code › Download ZIP) and open `presentation/index.html` in
a browser; the slides need the `presentation/media/` folder beside them.

| key | action |
|-----|--------|
| → ↓ space, or a click on the right | next slide |
| ← ↑, or a click on the left third | previous slide |
| F | full screen |
| N | speaker notes |

The animation of a slide plays, looping, while the slide is shown. The fonts
come from Google Fonts; offline, the slides fall back to Georgia and Arial.

## Sources

The video and the animations are drawn with Manim by `docs/video.py` on the
branch `ccr-45e3b350-7cdhp8`, whose docstring says how to render them.
