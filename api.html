API reference#

Everything below is re-exported from the top-level gemseo_box_subdivision namespace, which is what user code should import from.

The entry point#

gemseo_box_subdivision.scenario

A scenario solving a problem by subdividing its design space.

gemseo_box_subdivision.settings

The settings of a box-subdivision run, in the units the method measures.

gemseo_box_subdivision.convexity_sweep

Asking the master to sweep the convexity, rather than calibrating a value.

Subdivisions#

gemseo_box_subdivision.subdivisions.box

A Cartesian subdivision of a design space.

gemseo_box_subdivision.subdivisions.multi_resolution

A subdivision described by one categorical variable per level of refinement.

gemseo_box_subdivision.design_spaces

The design space of a box-subdivided problem.

Hierarchies#

gemseo_box_subdivision.hierarchy

Hierarchies of subdivisions: refining a box instead of subdividing it finely.

Disciplines#

gemseo_box_subdivision.disciplines.box_constraint

The box of a Cartesian subdivision, expressed as a constraint.

gemseo_box_subdivision.disciplines.box_mapping

The mapping from the normalized variables of a box to the design variables.

gemseo_box_subdivision.disciplines.multi_resolution_mapping

The mapping from the levels of a multi-resolution subdivision to the variables.

gemseo_box_subdivision.disciplines.scenario_adapters.box_start

A scenario adapter starting the sub-problem inside its box.
